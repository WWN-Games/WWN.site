# Ассеты и что где править

## Картинки

| Папка | Что лежит |
| --- | --- |
| `img/brand/` | логотип (`logo.svg`), favicon (`favicon.svg`), иконки манифеста (`icon-192.png`, `icon-512.png`) |
| `img/bg/` | фоны: `banner.webp` — первый экран, `og-banner.webp` — превью для соцсетей (og:image) |
| `img/factions/` | эмблемы фракций |
| `img/database/` | иконки базы данных: имя файла = `<id>` из `data/units.json` / `data/buildings.json` |
| `img/lore/` | картинки статей вики (карты эпох, территории, раса Вастт) |
| `img/gallery/` | скриншоты для галереи главной — см. `img/gallery/README.md` |

- Замена картинки — положить новый файл с тем же именем.
- Меняете имя или формат — поправьте путь в HTML, CSS, `js/site-config.js` или в статье вики.
- Галерея и статьи разделены: фото для галереи — только `img/gallery/`, картинки статей — только `img/lore/`. Если галерея пустая, её раздел на главной скрывается.

## Аудио

`audio/` — гимны и примеры речи. Подключаются в статьях вики блоком `.audio-card` (см. `../content/README.md`).

## Шрифты

`fonts/` — локальные вариативные woff2 в сабсетах latin/cyrillic: **Science Gothic** (дисплейный, `wght 100–900`), **Geist** (текст) и **Geist Mono** (код). Подключены через `css/fonts.css`, внешний Google Fonts не используется. Лицензии рядом: `OFL-ScienceGothic.txt`, `OFL-Geist.txt`, `OFL-GeistMono.txt`. Шрифты заданы переменными `--font-display` / `--font-body` / `--font-mono` в `style.css`; меняете набор весов или добавляете язык — обновите `fonts.css` и файлы в `fonts/`.

## JavaScript: что где менять

| Файл | Зачем |
| --- | --- |
| `js/site-config.js` | ссылки (Steam, Drive, Discord, YouTube), версия (она же ключ сброса кэша), новости, галерея |
| `js/i18n.js` | движок локализации RU/EN + общие строки |
| `js/i18n/home.js` | тексты главной |
| `js/i18n/wiki.js` | тексты вики |
| `js/i18n/database.js` | тексты базы данных |
| `js/utils.js` | общие утилиты: пути, локализация данных, форматирование, lite-режим |
| `js/ui.js` | шапка, меню, прогресс, появление блоков |
| `js/main.js` | главная: только сборка блоков |
| `js/home/hero.js` | hero: параллакс фона и ореола |
| `js/home/stats.js` | счётчики и живые числа (`stats-data.js` → `data/stats.json`) |
| `js/home/gallery.js` | галерея и лайтбокс (клавиатура, свайпы) |
| `js/home/news.js` | карточки новостей |
| `js/home/faq.js` | аккордеон FAQ |
| `js/stats-data.js` | живые числа сайта из `data/stats.json` (общий модуль главной и вики) |
| `js/media.js` | адаптивные картинки по `media-manifest.js` |
| `js/media-manifest.js` | размеры и варианты изображений: `srcset/sizes/width/height` |
| `js/wiki-shell.js` | оболочка вики: сайдбар, главная вики, поиск |
| `js/wiki.js` | статья вики: Markdown, оглавление, переходы (marked и DOMPurify грузятся динамически) |
| `js/database.js` | база данных: вкладки, фильтры, сортировка |
| `js/dropdown.js` | стилизованные выпадающие списки базы данных |
| `vendor/` | marked 18.0.13 + DOMPurify 3.4.15 (готовые ESM-сборки, не редактируются) |

- Ссылка с пустой строкой (`""`) в `site-config.js` скрывает кнопку или пункт меню автоматически.
- Данные базы данных и структура вики — в `data/`, статьи — в `content/` (там отдельные README).
- `data/stats.json` (цифры главной и вики) и `data/search-index-*.json` (поиск вики) — обычные JSON: правьте вручную при обновлении данных. Если `stats.json` нет, страницы возьмут значения из `site-config.js`; если нет индекса, поиск соберётся сам из markdown-файлов.
- `media-manifest.js` читают галерея и статьи вики. Добавили картинку — по желанию допишите в манифест её размеры и варианты (`<name>-640.webp` и т.п.); без записи картинка просто покажется без `srcset`.

## CSS

- `css/style.css` — дизайн-система и общие блоки (шапка, подвал, герой, карточки).
- `css/wiki.css` — только страницы вики.
- `css/database.css` — только страница базы данных.
- Эффект появления блоков (`[data-reveal]`) общий для всех страниц: триггер — константа `REVEAL` в `js/ui.js`, длительность/сдвиг/шаг каскада — переменные `--reveal-*` в `style.css`. Каскад задаётся атрибутом `data-reveal-delay` (1–3) или переменной `--reveal-delay`.

## Как посмотреть локально

Сайт использует ES-модули и `fetch()`, поэтому открывать его нужно через локальный сервер:

```bash
python3 -m http.server 8000
```

и зайти на <http://localhost:8000>.
