# Ассеты и что где править

## Картинки

| Папка | Что лежит |
| --- | --- |
| `img/brand/` | логотип (`logo.svg`), favicon (`favicon.svg`), иконки манифеста (`icon-192.png`, `icon-512.png`) |
| `img/bg/` | фоны: `banner-1440.avif` — первый экран по умолчанию (1440w) + `banner-960.avif` для узких экранов; `og-banner.webp` — превью для соцсетей (og:image), остаётся WebP: скраперы AVIF в превью не понимают |
| `img/factions/` | эмблемы фракций |
| `img/database/` | иконки базы данных (`.avif`): имя файла = `<id>` из `data/units.json` / `data/buildings.json` |
| `img/lore/` | картинки статей вики (карты эпох, территории, раса Вастт) |
| `img/gallery/` | скриншоты для галереи главной — см. `img/gallery/README.md` |

- Замена картинки — положить новый файл с тем же именем.
- Меняете имя или формат — поправьте путь в HTML, CSS, `js/site-config.js` или в статье вики.
- Галерея и статьи разделены: фото для галереи — только `img/gallery/`, картинки статей — только `img/lore/`. Если галерея пустая, её раздел на главной скрывается.
- Все растровые картинки страниц — **AVIF** (в WebP остаётся только `og-banner.webp`); галерея и картинки статей — одним файлом, без вариантов размеров. Исключение — фон-hero вики: `img/lore/tc-ru-960.avif` / `tc-en-960.avif` (1x) и полный `tc-ru.avif` / `tc-en.avif` (2x).
- Иконки базы (`img/database/`) хранятся шириной не более 256 px (бокс карточки — 78 px), при замене уменьшайте до 256 px по ширине.

### Пережатие (ffmpeg + avifenc)

```bash
# AVIF без альфы
ffmpeg -i in.webp -c:v libsvtav1 -crf 30 -preset 4 -pix_fmt yuv420p -svtav1-params tune=0 out.avif

# Вариант меньшего размера (только фон-hero вики): AVIF декодируется в PNG, затем масштабируется
avifdec in.avif tmp.png
ffmpeg -i tmp.png -vf "scale=960:-2:flags=lanczos" -c:v libsvtav1 -crf 30 -preset 4 -pix_fmt yuv420p -svtav1-params tune=0 in-960.avif

# AVIF с альфой — через avifenc (альфа-плоскость сохраняется)
ffmpeg -i in.webp out.png
avifenc -q 58 --qalpha 80 -s 6 out.png out.avif

# WebP (только og-banner)
ffmpeg -i in.webp -c:v libwebp -quality 78 -compression_level 6 out.webp
```

## Аудио

`audio/` — гимны и примеры речи. Подключаются в статьях вики блоком `.audio-card` (см. `../content/README.md`).

## Шрифты

`fonts/` — локальные вариативные woff2 в сабсетах latin/cyrillic: **Science Gothic** (дисплейный, `wght 100–900`), **Geist** (текст) и **Geist Mono** (код). Подключены через `css/fonts.css`, внешний Google Fonts не используется. Лицензии рядом: `OFL-ScienceGothic.txt`, `OFL-Geist.txt`, `OFL-GeistMono.txt`. Шрифты заданы переменными `--font-display` / `--font-body` / `--font-mono` в `style.css`; меняете набор весов или добавляете язык — обновите `fonts.css` и файлы в `fonts/`. Инлайн-скрипт в `<head>` страниц ставит `preload` для пары latin/cyrillic активного языка.

## JavaScript: что где менять

| Файл | Зачем |
| --- | --- |
| `js/site-config.js` | ссылки (Steam, Drive, Discord, YouTube) и версия (она же ключ сброса кэша) |
| `js/site-data.js` | данные главной: новости, галерея, теги (грузятся вместе с блоками главной) |
| `js/i18n.js` | движок локализации RU/EN + общие строки |
| `js/i18n/<page>.ru.js` / `<page>.en.js` | словари страниц по языкам; грузится только активный (второй — при переключении) |
| `js/utils.js` | общие утилиты: пути, локализация данных, форматирование, lite-режим |
| `js/ui.js` | шапка, меню (нативный popover), прогресс, появление блоков |
| `js/main.js` | главная: сборка блоков; интерфейс — сразу, тяжёлый рендер — после первого кадра |
| `js/home/hero.js` | hero: параллакс фона и ореола |
| `js/home/stats.js` | счётчики и живые числа (`stats-data.js` → `data/stats.json`) |
| `js/home/gallery.js` | галерея и лайтбокс (клавиатура, свайпы) |
| `js/home/news.js` | карточки новостей |
| `js/home/faq.js` | аккордеон FAQ |
| `js/stats-data.js` | живые числа сайта из `data/stats.json` (общий модуль главной и вики) |
| `js/media.js` | адаптивные картинки по `media-manifest.js` |
| `js/media-manifest.js` | размеры и варианты изображений: `srcset/sizes/width/height` |
| `js/wiki-shell.js` | оболочка вики: сайдбар, главная вики, поиск |
| `js/wiki.js` | статья вики: Markdown, оглавление, переходы (marked и DOMPurify грузятся динамически) |
| `js/database.js` | база данных: вкладки, фильтры, сортировка, кастомные выпадающие списки (Popover API) |
| `vendor/` | marked 18.0.13 + DOMPurify 3.4.15 (готовые ESM-сборки, не редактируются) |

- Ссылка с пустой строкой (`""`) в `site-config.js` скрывает кнопку или пункт меню автоматически. Значение может быть объектом `{ ru, en }` — тогда ссылка зависит от языка страницы (так сделана иконка YouTube в подвале: RU-языку — русский канал, EN — английский).
- Данные базы данных и структура вики — в `data/`, статьи — в `content/` (там отдельные README).
- `data/stats.json` (число карт и резерв для юнитов/фракций) и `data/search-index-*.json` (поиск вики) — обычные JSON: правьте вручную при обновлении данных. Юниты и фракции сайт считает сам по файлам базы (`assets/js/stats-data.js`); если `stats.json` нет, останутся запасные значения оттуда же; если нет индекса, поиск соберётся сам из markdown-файлов.
- `media-manifest.js` читают галерея и статьи вики: по нему `<img>` получает `width`/`height`, чтобы место под картинку резервировалось до загрузки. Добавили картинку — допишите в манифест её размеры; без записи картинка просто покажется как есть.
- Тексты интерфейса живут только в словарях `js/i18n.js` и `js/i18n/*.<lang>.js`. В HTML — пустые привязки `data-i18n*`; без JS страницы текстов не показывают (сайт рассчитан на работу с JS). Активный словарь страница догружает сама (`registerDictLoaders`), а в `<head>` ему заранее ставится `modulepreload`, поэтому лишнего round-trip нет.
- Тяжёлые модули главной и вики (`js/home/*`, `js/wiki-shell.js`) подключаются динамически уже после применения переводов: каркас и тексты не ждут их загрузки.

## CSS

- `css/style.css` — дизайн-система и общие блоки (шапка, подвал, герой, карточки).
- `css/wiki.css` — только страницы вики.
- `css/database.css` — только страница базы данных.
- Эффект появления блоков (`[data-reveal]`) общий для всех страниц: триггер — константа `REVEAL` в `js/ui.js`, длительность/сдвиг/шаг каскада — переменные `--reveal-*` в `style.css`. Каскад задаётся атрибутом `data-reveal-delay` (1–3) или переменной `--reveal-delay`.
- Пустые привязки `data-i18n*` резервируют одну строку (`[data-i18n]:empty::after` в `style.css`), чтобы появление текста не сдвигало уже отрисованный макет; в hero резерв отключён — там текст многострочный и резерв только вредит.
- Мобильное меню — нативный popover (`popovertarget` на бургере): открывается без JS, лок скролла и анимации — через `body:has(.mobile-nav:popover-open)` и `@starting-style`. Cross-document view transitions не используются (дают 300-мс снимок на каждом переходе).

## Как посмотреть локально

Сайт использует ES-модули и `fetch()`, поэтому открывать его нужно через локальный сервер:

```bash
python3 -m http.server 8000
```

и зайти на <http://localhost:8000>.
