# Скриншоты для галереи

Сюда складывайте **скриншоты из игры** — в галерее на главной показываются только они.

## Как добавить фото

1. Положите файл в эту папку, например `screenshot-1.jpg` или `art-1.png`.
2. Откройте `assets/js/site-config.js` и добавьте запись в массив `gallery`:

```js
gallery: [
  {
    src: "assets/img/gallery/screenshot-1.webp",
    wide: false,                                // широкая плитка (занимает 2 колонки)
    tall: false,                                // высокая плитка (занимает 2 ряда)
    ru: { caption: "Подпись на русском" },
    en: { caption: "Caption in English" }
  },
  // ...
]
```

3. Если галерея пустая — весь раздел на главной автоматически скрывается.

## Рекомендации

- Формат: **.webp** (легче и быстрее грузится).
- Ширина: **1600–2560 px**, вес до **700 КБ** на файл.
- Для широких кадров ставьте `wide: true`, для вертикальных — `tall: true`.

Картинки для статей вики (карты эпох, территории фракций, раса Вастт) лежат отдельно — в `assets/img/lore/`.
