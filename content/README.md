# Как добавлять статьи в вики

Статья — обычный Markdown-файл. Файлы лежат в `content/ru/` и `content/en/`, структура папок в обоих языках совпадает.

## Новая статья за три шага

1. Создайте файл на нужном языке, например `content/ru/guides/new-guide.md`, и такой же на втором языке — `content/en/guides/new-guide.md`.
2. Заполните шапку в начале файла:

   ```md
   ---
   title: Название статьи
   updated: 2026-09-15
   draft: true
   ---
   ```

3. Зарегистрируйте статью в `data/wiki-nav.json` в подходящей категории:

   ```json
   {
     "slug": "guides/new-guide",
     "title": { "ru": "Название статьи", "en": "Article title" },
     "desc": { "ru": "Краткое описание.", "en": "Short description." }
   }
   ```

   `slug` — путь к файлу без `content/<язык>/` и без `.md`. Порядок записей в массиве = порядок в меню и на главной вики.

## Шапка (front matter)

| Поле | Что делает |
| --- | --- |
| `title` | Заголовок статьи. В тексте `#` писать не нужно |
| `updated` | Дата в формате `ГГГГ-ММ-ДД`, выводится в подписи статьи |
| `draft: true` | Показывает бейдж «Черновик». Готово — поставьте `false` или удалите строку |

`title` в статье и в `wiki-nav.json` лучше держать одинаковыми.

## Текст и оглавление

- `##` и `###` автоматически попадают в оглавление (если заголовков меньше трёх, оглавление не выводится).
- Обычный Markdown: списки, **жирный**, таблицы — оформление подставляется сайтом.

## Ссылки и источники

- **На другую статью:** `[текст](overview.md)` или из подпапки `[текст](../factions/fenearth.md)` — сайт сам превратит их в правильный адрес.
- **На заголовок внутри статьи:** `[текст](#имя-заголовка)` — имя совпадает с id заголовка (например, `#карта-галактики`). Все заголовки `##`/`###` получают id автоматически.
- **На внешний источник:** обычная ссылка `[текст](https://example.org)` — она откроется в новой вкладке и получит пометку «↗».
- **На статью, которой ещё нет:** ссылка автоматически станет «красной» с подсказкой «Статья ещё не написана» — так видно, что статью ещё предстоит написать.
- **На файлы:** обычные относительные пути от статьи, например `../assets/img/lore/tc-ru.avif`.

### Блок «Источники» / «См. также»

В конце статьи можно добавить компактный блок со ссылками на источники или связанные статьи. Достаточно обычного заголовка с одним из названий — оформление подставится само:

```md
## Источники

- [Steam Workshop: мод WWN](https://steamcommunity.com/sharedfiles/filedetails/?id=3247893564)
- [GitHub: сообщить об ошибке](https://github.com/WWN-Games/WWN.issues/issues/new/choose)
- [История галактики](history.md)
```

Распознаются заголовки: **Источники**, **Ссылки**, **Внешние ссылки**, **См. также** (в EN — **Sources**, **Links**, **External links**, **See also**, **References**). Списки под таким заголовком оформляются компактнее, с линией-разделителем; внешние ссылки в них получают «↗», внутренние работают как обычные ссылки по вики.

### Сноски

В тексте можно ставить сноски — они становятся верхними индексами `[1]`, а внизу статьи появляется блок «Примечания» с обратными ссылками «↑»:

```md
Протонская армия формировалась в Территории Отен[^1], а её флот — на верфях Орбитальной суперверфи[^2].

[^1]: Подробнее — в статье [Движение Протон](proton.md).
[^2]: Данные с [сайта мода](https://example.org) на момент 3-й эпохи.
```

- Номер присваивается по порядку первого упоминания; повторная ссылка с тем же именем (`[^1]` дважды) ведёт на то же примечание.
- Внутри примечания работает обычный markdown: **жирный**, ссылки на статьи (`.md`) и внешние источники (получат «↗»).
- Имя сноски (`1`, `note`, `steam`) — любое, главное чтобы совпадало в тексте и в определении; определения пишутся отдельными строками в конце статьи.
- Блок «Примечания» автоматически добавляется в оглавление.

## Картинки

Картинка отдельным абзацем превращается в фигуру с подписью из alt:

```md
![Карта галактики в эпоху Тройственного Конфликта](../assets/img/lore/tc-ru.avif)
```

Несколько картинок в одном абзаце собираются в галерею.

Картинки статей кладите в `assets/img/lore/` (не в `assets/img/gallery/` — там только галерея главной). Подробнее — `../assets/README.md`.

## Особые блоки

- Аудио (гимны, примеры речи):

  ```html
  <div class="audio-card"><span class="audio-card__label">Гимн</span><audio controls preload="metadata" src="../assets/audio/fenearth-anthem.mp3"></audio></div>
  ```

- Выноски: `<div class="callout">текст</div>` и `<div class="callout callout--warn">текст</div>`.

## Два языка

- Статья должна существовать в обеих папках с одинаковым slug.
- Если `ru` и `en` совпадают (например, имя собственное), `en` можно не писать — подставится русское значение (так же в файлах `data/`).
- **Русский текст — источник истины.** Если формулировки в языках расходятся, английский переводится с русского, а не наоборот.

## Как посмотреть локально

Сайт использует ES-модули и `fetch()`, поэтому открывать его нужно через локальный сервер:

```bash
python3 -m http.server 8000
```

и зайти на <http://localhost:8000>.
