## Strict patch note format

The full change list for every version lives in the repository's **Commits / Releases** section. Below is a template that makes WWN patch notes easy to read and write.

### Added

- New units, maps, mechanics or features.

### Changed

- Balance tweaks: cost, health, damage, timings.
- Mechanics and UI reworks.

### Fixed

- Bugs, crashes, display and networking issues.

## How to report a balance change

1. Make sure the change is already in the latest release.
2. Describe what exactly changed and how it affected the game.
3. Attach a replay or screenshot on Discord or in Issues.
