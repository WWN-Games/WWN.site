# WWN — сайт мода для Rusted Warfare

Статический сайт мода WWN: лендинг со скачиванием, полная вики (лор, фракции, юниты, строения, механики, гайды, патчноуты) и каталог с фильтрами. Поддерживает **русский и английский** языки.

Готов к публикации на **GitHub Pages** без сборки: чистые HTML/CSS/JS, Markdown-контент и JSON-данные.

---

## Быстрый старт

### Как посмотреть сайт локально

Сайт использует **ES-модули** и `fetch()`, поэтому двойной щелчок по `index.html` не сработает. Запустите локальный сервер из папки сайта:

```bash
python3 -m http.server 8000
```

Затем откройте <http://localhost:8000>.

> Все страницы (включая главную) открываются только через локальный сервер или GitHub Pages.

### Как выложить на GitHub Pages

1. Создайте репозиторий на GitHub и залейте туда всё содержимое этой папки:

   ```bash
   git init
   git add .
   git commit -m "WWN site"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
   git push -u origin main
   ```

2. В репозитории: **Settings → Pages**.
3. Source: **Deploy from a branch**, Branch: **main**, папка: **/(root)**.
4. Через минуту сайт будет доступен по адресу `https://ВАШ_ЛОГИН.github.io/ВАШ_РЕПОЗИТОРИЙ/`.

Файл `.nojekyll` уже добавлен — он отключает обработку Jekyll, чтобы всё отдавалось как есть.

## Что и где редактировать

### 1. Ссылки на скачивание, версия, новости, галерея

**Файл: `assets/js/site-config.js`** — единственное место для ссылок.

```js
links: {
  steam: "https://steamcommunity.com/sharedfiles/filedetails/?id=3247893564",
  drive: "https://drive.google.com/file/d/1a3r6f3GG2pORNaqzCVBrsTKvrXs_ctYg/view?usp=sharing",
  discord: "https://discord.gg/sRwKDGrbDy",
  gitlab: "https://gitlab.com/wwn.games/wwn.mod-rustedwarfare/WWN-Mod",
  gameSteam: "https://store.steampowered.com/app/241100/Rusted_Warfare/",
  youtube: "", telegram: "", vk: "", github: "",
},
```

- Steam Workshop и Google Drive уже заполнены — кнопки на сайте активны.
- Пустая строка (`""`) = кнопка скрывается, а на карточке скачивания появляется плашка «Ссылка скоро появится».

Там же меняются:

- `version` и `updated` — бейдж версии в шапке;
- `stats` — цифры в блоке статистики;
- `news` — карточки в разделе «Что нового» (поддерживают теги `update`, `balance`, `league`, `fix`);
- `gallery` — картинки галереи (пути относительно папки сайта) с подписями на RU/EN.

### 2. Статьи вики

**Папка: `content/ru/` и `content/en/`** — обычные Markdown-файлы. Структура папок совпадает. Сейчас перенесена вся старая вики WWN-Lore:

| Папка | Что внутри |
| --- | --- |
| `lore/` | Вселенная, история галактики (8 эпох с картами), Фенземская Республика, Движение Протон, раса Вастт |
| `mechanics/` | Основные механики, экономика, война на земле и в космосе, WWN League |
| `guides/` | Установка и обновление, с чего начать, экономика, боевые тактики |
| `units/`, `buildings/` | Классы юнитов, строения и оборона |
| `misc/` | Контакты, вклад в мод |
| `changelog.md` | Патчноуты и ссылки на релизы |

Формат файла:

```md
---
title: Название статьи
updated: 2026-09-01
draft: true
---

Текст статьи в Markdown.

## Раздел

- списки
- **жирный**
- [ссылки на другие статьи](other-article.md)
```

- `title` — заголовок (выводится автоматически, в тексте `#` писать не нужно);
- `updated` — дата в формате ГГГГ-ММ-ДД;
- `draft: true` — показывает бейдж «Черновик». Когда текст готов, поставьте `draft: false` (или удалите строку);
- `##` и `###` автоматически попадают в оглавление статьи.

Внутренние ссылки: `[текст](overview.md)` или `[текст](../factions/fer.md)` — сайт сам преобразует их в правильный адрес.

**Особые блоки в статьях:**

- Картинка отдельной строкой превращается в фигуру с подписью (берётся из alt-текста):
  `![Карта галактики в эпоху Войны Очищения](../assets/img/lore/vo-ru.webp)`
- Аудио-плеер (гимны и примеры речи):
  `<div class="audio-card"><span class="audio-card__label">Гимн</span><audio controls preload="metadata" src="../assets/audio/fenearth-anthem.mp3"></audio></div>`
- Плашки-выноски: `<div class="callout">текст</div>`, `<div class="callout callout--warn">текст</div>`.
- Обычные Markdown-таблицы автоматически получают оформление сайта.

### 3. Структура вики (разделы и порядок статей)

**Файл: `data/wiki-nav.json`**

- `categories` — разделы бокового меню и главной вики;
- `icon` — иконка раздела: `book`, `shield`, `cube`, `gear`, `compass`, `clock`;
- `articles` — список статей; `slug` — путь к файлу без `content/<язык>/` и без `.md`.

Чтобы добавить статью: создайте файл `content/ru/ваш-раздел/ваша-статья.md` и `content/en/ваш-раздел/ваша-статья.md`, затем добавьте `slug` в `data/wiki-nav.json`.

### 4. Каталог (фракции, юниты, строения)

**Файлы: `data/factions.json`, `data/units.json`, `data/buildings.json`, `data/tags.json`**

Данные в компактном формате — одна запись легко читается и правится руками. Пример юнита:

```json
{
  "id": "akula",
  "name": { "ru": "Линкор \"Акула\"", "en": "Battleship \"Shark\"" },
  "faction": "fenearth",
  "type": "naval",
  "desc": { "ru": "Имеет две модификации • Имеет радар, сонар", "en": "Has two modifications • Has radar, sonar" },
  "tags": ["T2", "ship", "WATER"],
  "cost": 6000, "hp": 6500, "dps": 950, "speed": 0.7, "range": 600, "buildTime": 200
}
```

Правила формата (сверху каждого файла лежит та же памятка `_schema`):

- `id` — уникальный идентификатор. Картинка подставляется автоматически: `assets/img/catalog/<id>.webp`;
- `name`, `desc` — объекты `{ "ru": "...", "en": "..." }`. Если перевод совпадает, `en` можно не писать — подставится `ru`;
- `faction` — `id` из `factions.json`;
- `type` — для юнитов: `ground`, `air`, `naval`, `space`, `support`; для строений: `economy`, `defense`, `structure`;
- `tags` — список id тегов из `data/tags.json`. Показываются плашками на карточке, по ним же работает поиск;
- `cost`, `hp`, `shield`, `dps`, `speed`, `range`, `buildTime` — числа (`speed` — множитель скорости, `buildTime` — секунды, на карточке пишется с пометкой `1x`);
- `shield`, `dps`, `speed`, `range` можно не писать, если значение `0`;
- необязательное поле `image` переопределяет картинку (`"image": ""` — показать инициалы вместо картинки).

**Теги (`data/tags.json`)** — реестр всех тегов: `tier` (T1–T4, titan), `class` (корабль, суперкорабль, супертанк, супербот, космический суперкорабль, здание, суперздание, суперструктура…), `movement` (NONE, LAND, AIR, WATER, HOVER, BUILDING, OVER_CLIFF, OVER_CLIFF_WATER) и `mod` — все теги, найденные в конфигах мода.

- назначить тег: впишите его `id` в `tags` карточки;
- убрать тег: удалите `id` из `tags`;
- создать новый: добавьте запись `{ "id": "...", "name": { "ru": "...", "en": "..." }, "group": "..." }` в `tags.json` и используйте `id` в карточках. Незарегистрированный тег тоже покажется — просто как есть.

Полосы характеристик (прочность, щит, урон, скорость, дальность) строятся по **общей шкале для всех юнитов и строений**: максимум среди них = полная полоса, остальные значения — пропорционально меньше. Шкала не зависит от фильтров и вкладки.

Навигация каталога — вкладки (Фракции / Юниты / Строения), поиск и выпадающие фильтры по фракции и типу, плюс сортировка по имени, цене, прочности или урону.

### 5. Тексты интерфейса (кнопки, заголовки)

**Файл: `assets/js/i18n.js`** — словарь `ru` и `en`. Ключи вида `"nav.download": "Скачать"`.

### 6. Логотипы, картинки и звук

**Папки: `assets/img/` и `assets/audio/`**

| Папка / файл | Что это |
| --- | --- |
| `assets/img/brand/` | Логотипы, favicon, иконки сайта (`logo.webp`, `favicon*.png`, `apple-touch-icon.png`, `icon-512.png`) |
| `assets/img/bg/` | Фоны (`banner.webp` — первый экран, `space.webp` — раздел вики) |
| `assets/img/factions/` | Эмблемы фракций (`faction-fer.webp`, `faction-proton.webp`) |
| `assets/img/catalog/` | Иконки юнитов и строений каталога (`akula.webp`, `airfzr.webp`) |
| `assets/img/lore/` | Картинки для статей лора: карты эпох `dp…tc-{ru,en}.webp`, территории `map-fenearth/proton.webp`, раса Вастт |
| `assets/img/gallery/` | **Фотографии для галереи на главной.** Кладите сюда свои файлы и добавляйте записи в `gallery` в `site-config.js` (см. `assets/img/gallery/README.md`) |
| `assets/audio/` | Гимны Фензема и Протона, пример речи протонца (`*.mp3`) |

Галерея и лор разделены: фото для галереи — только `assets/img/gallery/`, картинки статей — только `assets/img/lore/`. Если галерея пустая, её раздел на главной автоматически скрывается.

Чтобы заменить картинку — просто положите новый файл с тем же именем. Если меняете формат/имя, поправьте пути в `index.html`, `site-config.js`, Markdown-статьях и JSON-файлах.

### 7. Лента лора на главной

**Файл: `assets/js/site-config.js`, массив `timeline`** — 8 эпох с картинками. Тексты эпох лежат в `i18n.js` (ключи `loresec.e1…e8`).

### 8. Лента новостей и галерея на главной

Там же в `site-config.js`:

- `news` — карточки новостей (дата, тег, заголовок и текст на RU/EN);
- `gallery` — скриншоты из игры; `wide`/`tall` — размер плитки, `srcEn` — версия картинки для английского. Фильтров нет: галерея показывает только кадры из игры.

## Что уже сделано

- **Современный стек**: ES-модули (`import.meta.url` вместо глобальных путей), Popover API в выпадающих списках, `<dialog>` для лайтбокса и поиска, `<search>`, View Transitions между страницами, `:has()`, `content-visibility`, web manifest, Speculation Rules (prefetch вики), `Intl` для дат и чисел.
- **Дизайн v2**: тёмная космическая тема, неоновые акценты, стеклянные панели, анимированный звёздный фон (звёзды, пыль, падающие звёзды), аврора и световые лучи, матовый слой, параллакс от курсора, scroll-progress, плавные появления секций, витрина фракций.
- **Реальные данные**: ссылки Steam Workshop, Discord, GitLab и Google Drive уже подключены.
- **Старая вики WWN-Lore перенесена**: 8 эпох истории с картами галактики, Фенземская Республика, Движение Протон, раса Вастт, гимны и пример речи — на русском и английском.
- **Каталог**: фракции, юниты и строения с фильтрами и характеристиками — реальные данные мода v1.1.6b9 (178 объектов), полосы по общей шкале (`data/*.json`).
- **Вики-движок**: боковая навигация, оглавление, время чтения, полнотекстовый поиск (`Ctrl+K`), черновики, переходы между статьями, поддержка RU/EN, плавные переходы между страницами.
- **Вики — отдельный раздел** (`/wiki/`), на главной её нет: доступна из верхнего меню, подвала и кнопок.
- **Адаптивность** и поддержка `prefers-reduced-motion`.

## Частые вопросы по редактированию

**Как убрать бейдж «Черновик» у статьи?**
В начале `.md`-файла замените `draft: true` на `draft: false`.

**Как добавить третьего языка?**
Скопируйте словарь в `i18n.js` под новым кодом, создайте `content/<код>/`, добавьте кнопку языка в HTML (`data-lang-btn="XX"`).

**Как поменять цвета сайта?**
`assets/css/style.css`, блок `:root` — переменные `--cyan`, `--bg-*`, `--red` и т.д.

**Поиск в вики не находит статью.**
Поиск работает по текущему языку сайта: если интерфейс на английском, ищутся английские тексты.
