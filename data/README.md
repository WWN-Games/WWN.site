# Данные сайта

## База данных

| Файл | Что внутри |
| --- | --- |
| `units.json` | юниты |
| `buildings.json` | строения |
| `factions.json` | фракции (цвет, эмблема, лор, сильные/слабые стороны) |
| `tags.json` | реестр тегов базы данных |
| `wiki-nav.json` | разделы и статьи вики |
| `stats.json` | цифры главной (юниты + строения, фракции, карты, статьи) |
| `search-index-ru.json`, `search-index-en.json` | поисковый индекс вики (текст статей без разметки) |

- Формат и все поля описаны в самом верху каждого файла — в блоке `_schema`. Пример юнита там же.
- **Русский текст — источник истины**: если `ru` и `en` расходятся по смыслу, переводится с русского. Единые термины и аббревиатуры — в `../content/README.md`.
- Картинка подставляется автоматически по `id`: `assets/img/database/<id>.webp`. Переопределить можно полем `image`, а `"image": ""` показывает инициалы. Подходящего id нет — карточка честно покажет инициалы.
- Необязательные поля карточек, которые поддерживает интерфейс: `role` — роль `{ ru, en }`, `strongVs`/`weakVs` — списки или строки `{ ru, en }` («Сильно/слабо против»), `draft: true` — бейдж «Черновик».
- Теги: сначала добавьте запись в `tags.json`, затем впишите её `id` в поле `tags` карточки. Незнакомый тег всё равно покажется — просто как есть.
- Полосы характеристик (прочность, щит, урон, скорость, дальность) считаются автоматически по общей шкале всех юнитов и строений — задавать максимумы вручную не нужно.
- `stats.json` — цифры для главной. Это обычный JSON, правьте вручную при изменении состава юнитов/строений/фракций. Если файла нет, главная возьмёт значения из `stats` в `assets/js/site-config.js`.
- `search-index-*.json` — текст статей без markdown для поиска на страницах вики. После правки статей обновите индекс (или удалите файлы: тогда поиск соберётся сам из `content/`, но это ~30 запросов).

## Структура вики: `wiki-nav.json`

- `categories` — разделы бокового меню и главной вики.
  - `id` — идентификатор раздела;
  - `icon` — одна из иконок: `book`, `shield`, `cube`, `gear`, `compass`, `users`, `clock`;
  - `title`, `desc` — подписи `{ ru, en }`;
  - `articles` — статьи раздела по порядку.
- `articles` — записи вида `{ "slug": "lore/overview", "title": {…}, "desc": {…} }`.
  - `slug` — путь к файлу без `content/<язык>/` и без `.md` (файл должен существовать в `content/ru/` и `content/en/`).

Как создать и оформить саму статью — см. `../content/README.md`.
