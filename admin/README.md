# WWN Admin

Локальная админка для контента сайта: статьи вики, карточки базы, загрузка
изображений, валидация и git-операции.

## Запуск

```bash
pnpm install
pnpm admin
```

Откройте <http://127.0.0.1:4322>. Dev-сервер сайта (`pnpm dev`) запускается
отдельно — админка показывает его статус и preview.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `ADMIN_HOST` | `127.0.0.1` | Интерфейс прослушивания |
| `ADMIN_PORT` | `4322` | Порт админки |
| `SITE_ORIGIN` | `http://127.0.0.1:4321` | Origin dev-сервера сайта |
| `ADMIN_ORIGIN` | — | Дополнительный разрешённый Origin (нужен при `ADMIN_HOST` вне loopback) |

## Ограничения

- Аутентификации нет. Не выставляйте сервер в публичную сеть.
- Запись и git-операции выполняются в рабочей копии репозитория; коммит
  затрагивает только выбранные файлы.
- Проверка типов: `pnpm --dir admin check`; сборка: `pnpm --dir admin build`.
