# Дизайн-система WWN

Единый визуальный язык сайта и локальной админки. Значения живут в `src/styles/tokens.css`, общие примитивы — в `src/styles/ui.css`.

## Слои стилей

| Файл | Назначение |
| --- | --- |
| `tokens.css` | только CSS-переменные: цвет, отступы, типографика, радиусы, тени, движение |
| `ui.css` | общие примитивы: page-intro, catalog-card, toolbar, table, empty-state |
| `style.css` | сброс, базовая типографика, каркас сайта и главная |
| `database.css` | только страница базы |
| `wiki.css` | только вики |
| `admin/src/app.css` | только админка, использует те же токены |

## Отступы

Шкала: `--space-1` (4px) … `--space-13` (120px). Новые отступы не пишем произвольными значениями.

- секция сайта — `--section-space`;
- внутренняя страница — `--section-space-sm` сверху;
- сетка карточек — `--grid-gap`;
- карточка — `--card-pad`;
- компактные элементы админки — `--space-2` / `--space-3`;
- поля и панели админки — `--space-4` / `--space-5`.

## Типографика

- `--text-2xs` … `--text-3xl` — шкала размеров;
- `--text-section` — заголовки секций;
- `--line-tight` / `--line-normal` / `--line-relaxed` — межстрочные;
- `--tracking-*` — трекинг для капса и служебных подписей.

Заголовок внутренней страницы — `PageIntro.astro` с `.page-intro`.

## Радиусы

- `--radius-1` — чипы и мелкие элементы;
- `--radius-2` — контролы;
- `--radius-3` — вложенные поверхности;
- `--radius-4` — карточки и панели;
- `--radius-5` — крупные диалоги;
- `--radius-pill` — пилюли и переключатели.

## Цвета

Палитра прежняя: тёмный космос, голубой акцент, золото и красный для статусов. Семантические псевдонимы: `--color-bg`, `--color-surface-*`, `--color-border*`, `--color-text*`, `--color-accent*`, `--color-danger`, `--color-warning`, `--color-success`.

Фракционный цвет по-прежнему приходит через `--faction-color`.

## Компоненты

- `.page-intro` — заголовок страницы;
- `.catalog-grid` / `.catalog-card` — каталоги (карты, видео, подвиги);
- `.page-toolbar` — поиск, сортировка, фильтры;
- `.segmented` — переключатели;
- `.data-table` — таблицы;
- `.empty-state` — пустые состояния;
- `.surface-panel` — панели;
- `.chip`, `.badge`, `.btn` — общие элементы.

## Правила

- Все интерактивные элементы имеют один focus-ring.
- Карточки в каталоге одной высоты, действия прижаты к низу.
- Таблицы всегда в `.data-table-wrap` с горизонтальным скроллом.
- На мобильных не скрываем важные колонки и действия — используем скролл.
- Уважаем `prefers-reduced-motion`.
- Новые страницы используют `PageIntro` и общие примитивы, а не собственные заголовки и карточки.

## Контрольные точки

Основные: 1240 / 1024 / 900 / 720 / 560 px. В вики дополнительно используется 1040 px для перестройки сайдбара. Точечные исключения допустимы только там, где контент реально ломается.
